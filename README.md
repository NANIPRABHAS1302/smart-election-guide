# Smart Election Guide (India)

## Problem
Many citizens, especially first-time voters, lack awareness about the election process, required documents, and concepts like NOTA.

## Solution
This project is an AI-powered Smart Election Guide that provides simple, step-by-step explanations about elections through a conversational interface.

## Features
- AI chatbot for election queries
- Step-by-step voting guidance
- English + Telugu support
- Explanation of NOTA and documents
- Beginner-friendly interface

## Tech Stack
- Replit AI
- Node.js

## How It Works
User asks a question → AI processes it → returns a simple and helpful explanation.
